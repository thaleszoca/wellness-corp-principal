# Wellness

Projeto de questionário adaptativo de nutrição e bem-estar.

## Estrutura

- `CLAUDE.md`: instruções principais para o Claude.
- `docs/`: documentação conceitual e regras do sistema.
- `questionnaire/`: banco de perguntas, respostas, fluxo e pontuação.
- `objectives/`: regras específicas de cada objetivo.
- `outcomes/`: categorias, subcategorias e recomendações finais.
- `tests/`: cenários de teste e resultados esperados.
