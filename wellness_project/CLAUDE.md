# Instruções para o Claude

1. Leia `README.md` e `docs/estrutura-completa-questionario.md` antes de alterar o projeto.
2. O usuário deve responder exatamente 40 perguntas.
3. O caminho deve depender das respostas anteriores.
4. As perguntas devem relacionar mente, alimentação atual e impacto físico.
5. Não repetir perguntas.
6. Exibir uma mensagem curta de motivação a cada 5 perguntas.
7. Não inventar categorias, subcategorias ou critérios sem registrar a alteração.
8. Toda regra de direcionamento deve ser explícita e testável.
9. Termos clínicos não devem ser apresentados como diagnóstico.
10. Atualize os testes sempre que modificar o fluxo.
